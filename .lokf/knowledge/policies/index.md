# Policies

* [AI covenant](ai-covenant.md) - The rules for AI-assisted work here: whoever submits owns the contribution, an element names its clause or control and quotes none of it, no ISO text goes anywhere in the repository, and ISO's metadata records are never edited.
* [Security policy](security-policy.md) - How to report a vulnerability in this repository, by GitHub's private reporting, what executes here and what holds each surface. A problem in the standard belongs with its committee.
* [Licence and attribution](license-and-attribution.md) - Whose work each part is: the code and schema under Apache-2.0, the bundle under CC BY 4.0, ISO's metadata records under ODC-By, and the standard's text, which the repository does not hold.
